# Skill Stack Podcast - Show Branding

---

## Show Name Options

### Option 1: "Skill Stack" (Current)
- **Pro:** Matches the blog, consistent brand
- **Con:** No natural rhyme, "podcast" doesn't flow

### Option 2: "The Stack"
- **Pro:** Shorter, punchy, "Welcome back to the Stack" works
- **Con:** Less descriptive, might get lost in search

### Option 3: "Stack Attack"
- **Pro:** Rhymes, energetic, memorable
- **Con:** Aggressive tone might not fit

### Option 4: Keep "Skill Stack" but use "The Stack" in casual references
- "Welcome back to the Stack" (short form)
- "This is the Skill Stack podcast" (long form)

---

## Opening Line Options

### The Alliterative ("Source, Substance, Style")

> "Source. Substance. Style. This is Skill Stack."

Clean, references the 4S framework, rhythmic.

---

### The Rhyming Hook

> "Welcome back to the Stack - where we transform, not generate."

Callback to the core philosophy.

---

### The Punchy Return

> "You're back. This is the Stack. Let's build."

Short, direct, action-oriented. Works for returning viewers.

---

### The Philosophy Drop

> "The bottleneck isn't AI. It's your context. This is Skill Stack."

Leads with the core insight.

---

### The Casual Confidence

> "Hey, it's Charlie. This is Skill Stack - let's stack some skills."

Personable, low-key, works for solo episodes.

---

### The Contrarian Open

> "Everyone's using AI. Almost nobody's using it well. This is Skill Stack."

Sets up the problem, positions the show as the solution.

---

### The Guest Intro Version

> "Source. Substance. Style. This is Skill Stack - and today I'm talking with [GUEST]."

Works when you have a guest.

---

## My Recommendation

**For solo episodes:**
> "Source. Substance. Style. This is Skill Stack."

**For guest episodes:**
> "Source. Substance. Style. This is Skill Stack - I'm Charlie Deist, and today [GUEST] is here to [TOPIC]."

**For casual/returning:**
> "Welcome back to the Stack."

## Audio Branding Notes
