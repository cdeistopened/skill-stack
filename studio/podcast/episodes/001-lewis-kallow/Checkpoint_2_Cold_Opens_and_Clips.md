# Checkpoint 2: Cold Opens & Clips - Lewis Kallow Episode

**Approved Story Arc:** The 2000-Word Prompt Problem
**Big Idea:** Examples beat instructions (backed by research on 500+ techniques)

---

## Cold Open Script

**Duration:** ~28 seconds
**Structure:** Host intro → Guest excerpt (teases insight, cuts before answer)

```
(00:00-00:10) [HOST INTRO - Record separately]
CHARLIE: Most people write AI prompts all wrong. They think more
detail means better output. Lewis Kallow found out the hard way
that it's the opposite.

(00:10-00:28) [LEWIS EXCERPT - From 00:03:46]
LEWIS: A few months after that article came out, there was a study,
an academic study that was released and it looked at over 500
prompting techniques. And it found that the single most effective
prompting technique is just showing the AI examples.

[CUT TO: "Lewis, great to have you here..."]
```

**Quality Gates:**
- [x] Stranger: Opens with contradiction ("more detail = worse")
- [x] Itch: "500 techniques" creates research credibility + curiosity
- [x] Stakes: Everyone writes prompts; this changes how they do it
- [x] Tease: Reveals the answer (examples) but doesn't explain WHY
- [x] Emotion: Validation for anyone frustrated with long prompts

### Clip 3: "The Knowledge Management Dream" (THE PAYOFF)

**Timestamp:** 01:01:36 - 01:02:23

**On-Screen Hook:** THE DREAM WE WERE PROMISED

```
LEWIS: I think the really key thing that's happening here is that
you've just said, 'Hey, go and update my system' and it's just
```

### Clip 4: "Old Way vs New Way" (THE EXPLAINER)

**Timestamp:** 00:21:40 - 00:22:54
**Duration:** ~74 seconds (longest - best for YouTube Shorts)
**On-Screen Hook:** BEFORE → AFTER

```
LEWIS: To understand Claude skills, you need to understand what
Claude Code is. One way of doing that is to compare the before
and after of the workflow. It used to be that the AI would give
you the code and then you would copy and paste that into the file.
You'd figure out where to put it. Then you'd click run to see
whether the code actually works. Oftentimes there'd be errors.
So you'd copy and paste those errors, go back to the AI chat
window and be like, 'Hey, there are these errors - why is that
happening?' The AI would go, 'Ah, here's the code you need to
change.' So back to Xcode, copy and paste the new code. Try again.

All of that now happens in one prompt. You go to Claude and say,
'Build this feature' - and it will edit all of your files for you.
```

**Platform:** YouTube Shorts (longer format works here)
**Best for:** People who haven't tried Claude Code yet
**Why it works:** Clear before/after contrast; the "all of that now happens in one prompt" is the money line

## Design Specifications

- Duration: Display for 3-4 seconds at hook moment

- Active word highlighted in yellow (#ffd02b)
- All clips need full captions for sound-off viewing

- All clips: 9:16 vertical
