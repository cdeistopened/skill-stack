## Product Architecture

### Doodle Reader (Core Product)
The universal markdown converter. Everything flows through here:
- PDF → Markdown (OCR)
- Podcast RSS → Markdown (transcripts)
- YouTube → Markdown (captions)
- Web → Markdown (articles)

**Why it matters**: Markdown is the universal input format for AI. Doodle Reader is the on-ramp.

### Skills (Output of Doodle Reader)
Skills are a special type of structured markdown - frameworks that transform AI into domain experts. Doodle Reader creates the source material; Skills are what you build from it.

**The loop**: Source Material → Doodle Reader → Markdown → Skills → Better AI outputs

### Echo Base (Subsumed into Doodle Reader)
The content repurposing features (4S framework, daily content proposals, etc.) become part of Doodle Reader's capabilities, not a separate product.

## The Skill Stack Framework

### 4S Framework (Your Core Teaching)

**Source** → **Substance** → **Structure** → **Style**

1. **Source**: Raw material (transcripts, articles, highlights)
2. **Substance**: The point, the big idea, the take
3. **Structure**: Format/framework (templates, outlines)
4. **Style**: Voice, aesthetic, write-print

This is what you teach. Every video ties back to this.
