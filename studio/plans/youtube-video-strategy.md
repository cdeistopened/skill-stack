# Skill Stack YouTube Strategy

**Goal:** 100K subscribers by Dec 2026
**Informed by:** Pre-mortem analysis, SEO/competitor research (Jan 2026)

---

## The Pivot

Pre-mortem risks: part-time effort, narrow niche, perfectionism.

**Solutions:**
- Broader keywords (Claude Code, MCP, AI agents) vs. "context engineering"
- Shorts-first approach for faster production
- Signature series ("One Skill") reduces decision fatigue
- 12 hours/week max, 4.5 hours per long-form video cap

## Shorts Strategy: "One Skill" Series

**Format:** One specific skill. No intro. 15-30 seconds. Straight to the thing.

**Signature closing:** "That's a skill."

### Claude Code Skills

- The /add-dir skill (folder to context in 2 sec)
- The CLAUDE.md skill (memory across sessions)
- The glob pattern skill (`**/*.tsx` finds everything)
- The checkpoint skill (revert bad changes instantly)
- The multi-file edit skill (5 files, one shot)
- The MCP skill (connect Notion/Slack/GitHub in one line)
- The screenshot skill (paste image, Claude codes to match)
- The permission prompt skill (flow state via settings.json)

### Workflow Skills

- The voice-to-code skill (Wispr Flow → Claude)
- The diff review skill (always read before accepting)
- The commit message skill (/commit writes better than you)
- The refactor skill ("make this cleaner")
- The test-first skill (write test in English, Claude writes code)
- The parallel agent skill (multiple Claudes, different tasks)

### Context Engineering Skills

- The corpus skill (feed Claude your writing, it writes like you)
- The voice skill (one markdown file captures how you write)
- The anti-AI skill (rules that make output not sound like AI)
- The constraint skill ("never use these words" improves output)
- The example skill (show 3 examples > describe what you want)
- The chain skill (output of skill 1 → input of skill 2)

## Pre-Launch Requirements

From premortem - don't launch without:
- Twitter to 5K+ followers (warm audience)
- 3 collaboration partners confirmed
- 4-week content buffer (8 videos scripted, 4 filmed)
- Email lead magnet live

## Month 3 Decision Point

Revise strategy if:
- Subscribers < 2,000
- AVD < 40%
- Browse traffic < 15%
- Shorts avg < 1,000 views
