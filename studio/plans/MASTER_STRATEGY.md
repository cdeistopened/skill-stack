## Stack: The Cloud Workbench

The "Stack" is where Cloud Sandbox meets Writer's IDE. A cloud-hosted environment where users can:

1. **Experiment with skills** - Try before installing locally
2. **Import knowledge** - YouTube transcripts, PDFs, RSS feeds via Doodle Reader integrations
3. **Create skills** - Guided wizard for building custom skills
4. **Share skills** - Push to GitHub, get discovered in marketplace
5. **Learn GitHub** - On-ramp to version control for non-developers

**Implementation:**
- Lightweight VPS (Railway/Fly.io) running skill executor
- File upload → skill selection → output preview
- Free tier: 3 runs/day, 10MB limit
- Guild tier: Unlimited, persistent workspace

**Strategic note:** This replaces the "Corpus" desktop app vision. Web-first is the right call for distribution.

## The Core Thesis

**Model intelligence is no longer the bottleneck. Context engineering is.**

Everyone has access to the same AI models. The differentiator is:
- Your raw material (substance)
- Your voice (style)
- Your workflows encoded as skills (structure)

Skills are repeatable processes that transform your raw material into shareable content. They're yours. You build them. You own them.

## The Four Pillars

### 1. Transform, Don't Generate
AI refines human ideas, not replaces them. Your raw material is the secret ingredient.

### 2. Flow, Not Code
Dictation + beginner's mind. English is the hottest programming language.

### 3. Wide, Not Deep
Conduct multiple threads. The conductor, not the monk.

### 4. Liberation, Not Replacement
AI as tool of distribution, not concentration. Own your tools.

## The Marketplace Vision

See [expert-to-skill-marketplace.md](expert-to-skill-marketplace.md) for full PRD.

### The Insight

Everyone's building skills marketplaces. Nobody's solving the **supply problem**.

The unlock: **Any expert's methodology can become a skill.** They don't need to know Claude Code. They just need content.

### The Four Layers

```
1. REFINERY      Expert content → Installable skills (supply)
2. REGISTRY      GitHub + Discovery layer (distribution)
3. INSTALLER     Portability wizard (friction reduction)
4. SANDBOX       Cloud-hosted "Try Now" (conversion)
```

### The Unlock: Cloud Sandbox

Most users bounce before trying a skill because setup is too hard.

The sandbox lets them: Upload files → Select skill → See output → No installation.

- Free: 3 runs/day, 10MB limit
- Guild: Unlimited, persistent workspace
- Tech: Railway/Fly.io VPS or lightweight skill runner

### Creator Economics Summary

- 30% of Guild revenue → creator pool
- Points = Stars + Installs + Active Users
- Tiers: Contributor → Creator → Expert → Legend
- Forks: 80/20 split (fork/original)
- Chains: Each skill earns independently

## Competitive Position

### What We're Not

- **Not a prompt marketplace** - Skills > prompts
- **Not a course platform** - Tools you use daily, not one-time learning
- **Not an AI wrapper** - You own the skills, no lock-in

### What Makes Us Different

| Competitor | Their Approach | Our Advantage |
|------------|----------------|---------------|
| skills.sh | General marketplace | Expert-to-skill pipeline (supply) |
| PromptBase | Selling prompts | Full workflows, not one-shots |
| AI courses | One-time learning | Ongoing tools + community |
| Agencies | Done-for-you | Done-with-you + skill ownership |

### Moat

1. **Existing corpus** - 80+ production-tested skills
2. **Expert-to-skill pipeline** - Methodology for extracting skills from content
3. **Voice codification** - The voice-analyzer → anti-ai-writing system
4. **Production credentials** - Naval, OpenEd, real work at scale
5. **Community** - Guild members contributing and iterating
