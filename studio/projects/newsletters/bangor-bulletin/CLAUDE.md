# Bangor Bulletin - Project Context

> Axios for the Foothills. A hyper-local newsletter for Bangor, California.

## What This Is

The Bangor Bulletin is a weekly email newsletter that digitizes the feed store bulletin board and connects a rural community of ~500 people. It's also the **demo project** for the Skill Stack YouTube series - showing how one person can build a local media operation using AI skills.

## The Thesis

From the Rerum Novarum essay:

> "AI creates a fork in the road. Path one: tool of concentration - big business squeezes more from fewer workers. Path two: tool of distribution - small operators do what only large organizations could do before."

The Bangor Bulletin is proof of Path Two. One person, serving 500 neighbors, using skills to do what would have required a small team.

## Voice: Pirate Wires Meets Tractor Supply

- **Smart brevity** - No fluff. Bold headers, bullet points. Respect the reader's time.
- **Pro-neighbor, pro-autonomy** - Celebrate self-reliance, local trade, practical cooperation.
- **Tactical transparency** - Call it like you see it.
- **Conversational** - Write like you're talking to a neighbor at the feed store.

Signature moves:
- "This is insane" (for obvious absurdity)
- "Used to be normal" (frame cooperation as common sense)
- "Here's the thing" (direct entry into content)

## Workflow

1. **Weekly board scan** - Photo bulletin boards at feed store and post office
2. **Extract with vision AI** - Gemini or Claude to parse images into structured data
3. **Update master list** - Add new listings, remove expired ones
4. **Draft issue** - Lead story + Quick Hits + Directory sections
5. **Apply voice guide** - Edit for Pirate Wires style
6. **Send** - Weekly on [TBD day]
