# Post Idea: One Line Makes Skills Self-Improving

**Status:** Idea for Skill Stack blog
**Hook:** "This one line prompt makes any skill continuously self-improving"

---

## The Concept

Add language to skills (or to CLAUDE.md) that triggers automatic improvement suggestions:

> "Every time we run this skill, before compacting context, proactively propose improvements to the skill for review."

Or as a global instruction:

> "After completing any skill, look for learnings and suggest refinements."

## Why It Works

- Skills evolve from usage patterns
- User doesn't have to remember to improve
- Creates compounding knowledge over time
- Low friction continuous learning

## Post Structure

1. The problem: skills get stale
2. The one-line fix
3. Examples of improvements caught
4. How to add it to your own skills
